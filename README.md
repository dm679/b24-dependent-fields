# Зависимые поля в карточке сделки Битрикс24

Прототип формы с **многоуровневыми зависимыми полями**: значение в одном поле
открывает свой набор дочерних полей, другое значение — другой набор. Скрытые
поля плавно сворачиваются, их значения очищаются. Данные пишутся в
**пользовательские поля сделки** (`UF_CRM_*`).

## Файлы

| Файл         | Назначение |
|--------------|------------|
| `schema.js`  | Декларативное описание полей и условий `showIf`. **Здесь меняешь логику.** |
| `engine.js`  | Движок: рендер, пересчёт видимости (любая вложенность), анимация. Не зависит от Б24. |
| `app.js`     | Связка с Б24: `crm.deal.get` / `crm.deal.update`, дебаунс-сохранение. |
| `styles.css` | Внешний вид + плавное появление (трюк с `grid-template-rows: 0fr → 1fr`). |
| `index.html` | Точка входа, подключает BX24 SDK. |

## Как добавить/изменить зависимость

Правишь только `schema.js`. Пример вложенности 2-го уровня:

```js
{ code: 'UF_CRM_HAS_VAT', label: 'Работаете с НДС?', type: 'select',
  options: [{value:'yes',label:'Да'},{value:'no',label:'Нет'}],
  showIf: (v) => v.UF_CRM_CLIENT_TYPE === 'company' },

{ code: 'UF_CRM_VAT_RATE', label: 'Ставка НДС', type: 'select',
  options: [{value:'20',label:'20%'}],
  showIf: (v) => v.UF_CRM_CLIENT_TYPE === 'company' && v.UF_CRM_HAS_VAT === 'yes' },
```

`showIf` получает значения ВСЕХ полей. Если родитель скрылся — его значение
очищается, поэтому потомки скрываются автоматически (цепочки любой глубины).

## Установка в Битрикс24

1. **Создай пользовательские поля сделки** (CRM → Настройки → Пользовательские
   поля, или прямо в карточке сделки) с кодами из `schema.js`:
   `UF_CRM_CLIENT_TYPE`, `UF_CRM_COMPANY_NAME`, `UF_CRM_INN`, `UF_CRM_HAS_VAT`,
   `UF_CRM_VAT_RATE`, `UF_CRM_PASSPORT`, `UF_CRM_BIRTH_DATE`, `UF_CRM_COMMENT`.
   Тип — строка/список/дата по вкусу (хранение строкой подойдёт для прототипа).
2. **Залей файлы** на HTTPS-хостинг (или в локальный dev через туннель).
3. **Зарегистрируй приложение** на frigat.bitrix24.eu:
   Разработчикам → Другое → Локальное приложение.
   - Путь обработчика: URL твоего `index.html`.
   - Права (scope): `crm`.
   - Добавь placement-обработчик `CRM_DEAL_DETAIL_TAB`
     (через `placement.bind` или REST `placement.bind`) — тогда приложение
     появится отдельной вкладкой прямо в карточке сделки.
4. Открой любую сделку → вкладка приложения → форма подтянет текущие значения
   и будет сохранять изменения на лету.

### Привязка вкладки (placement.bind), пример REST

```
placement.bind
  PLACEMENT = CRM_DEAL_DETAIL_TAB
  HANDLER   = https://твой-домен/dependent-fields/index.html
  TITLE     = Параметры клиента
```

## Локальная проверка без Битрикса

Просто открой `index.html` в браузере — форма запустится в демо-режиме
(без сохранения), чтобы посмотреть поведение зависимостей и анимацию.

## Дальше — к «инлайн прямо в поле»

Движок (`engine.js`) намеренно отвязан от Б24. Чтобы перейти к инлайн-варианту
внутри нативного поля карточки, переиспользуем тот же `DependentForm`, поменяв
только точку монтирования и источник значений в `app.js`.
